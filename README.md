# Aura Idle

RPG idle em 3D feito com Three.js (r128), num único arquivo `index.html`, sem build.

## Como rodar
Abra `index.html` no navegador (precisa de internet para carregar o Three.js da CDN).
Ou: `npx serve .` e acesse http://localhost:3000.

## Sistemas
Auras (10 tiers), classes (Cavaleiro, Mago, Arqueiro, Paladino) com ataque especial,
itens (8 raridades, 7 espaços), baús, mascotes, Torre, Jornada (missões, login diário,
conquistas, loja), talentos, eventos diários, ascensão com cosméticos, perfil com retratos e molduras.
